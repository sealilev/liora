# כלים לעמוד הצילום

## הוספת תמונה / סבב תמונות
1. לשים את התמונה הנקייה (בלי סימן מים) ב־`photography/originals/<שם התמונה>.png`
2. להוסיף/לעדכן את השורה שלה ב־`photography/data/photos.csv` (עם כל המחירים)
3. להטביע סימן מים:
   ```bash
   python3 photography/tools/bake_watermark.py "שם התמונה"
   ```
4. לעדכן את הנתונים של האתר:
   ```bash
   python3 photography/tools/csv_to_photos_json.py
   ```

## כללים ב־photos.csv
- רק השורות **מעל השורה הריקה הראשונה** מופיעות באתר. מה שמתחתיה בחניה.
- קטגוריה 1–5 = מקום בקרוסלת "השבוע"; שם קטגוריה = גלריה.
- שורה עם מחיר חסר מדולגת (עם אזהרה) ולא מופיעה באתר.
- מחירי היורו מחושבים אוטומטית: מחיר בשקלים ÷ 4.

דרישה חד־פעמית: `python3 -m pip install --user Pillow`
